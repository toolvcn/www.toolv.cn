# 人民币大写 · /rmb-uppercase

> 在线使用：<https://www.toolv.cn/rmb-uppercase> ・ 数据全部本地处理，不上传、不落库

- **按票据规范输出**：`10` 写作「壹拾」、中间连续零只写一个、万 / 亿大单位在零位不丢（`10000000` → 壹仟万）、角分全零加「整」、角零分不零写「零X分」
- **输入宽容**：接受千分位逗号与空白，第三位小数自动四舍五入到分（`1.999` → 贰圆整），支持负数（前缀「负」）
- **4 位分段算法**：整数按万进制逐节转换，支持到千万亿（16 位），全程字符串逐位处理不经浮点数
- 输入即转，大字号展示结果，一键复制，纯本地计算

## 参数在哪调

没有 `config.ts`，可调常量在 `core/types.ts` 与 `core/rmb.ts`：

- `EXAMPLE_INPUT = '1,234,567.89'`：首屏示例（带千分位逗号与两位小数）
- `MAX_INTEGER_DIGITS = 16`：整数部分位数上限（千万亿以内），超出给中文提示
- 进位 / 单位规则（`DIGITS` / `GROUP_UNITS` / `SECTION_UNITS`）与小数第三位四舍五入逻辑都在 `core/rmb.ts`

## 档位

**L2**（+page.svelte + core/ 纯函数 + ui/ 面板）：`core/rmb.ts`（normalize / integerToChinese / toRmbUppercase，全程 BigInt + 字符串逐位处理）+ `core/store.svelte.ts` + `core/types.ts`。

## 实现口径

- **全程不经浮点数**：用户输入先 `normalize` 成 `[-]整数(.角分)`，第三位小数四舍五入进分；进位连锁滚过两位小数（`0.999 → 1.00`）时整数部分用 BigInt 加一，避免浮点误差
- **4 位分段逐节转换**：整数按万进制分节（个 / 万 / 亿 / 万亿），高到低逐节拼；万 / 亿这类大单位在零位也不丢（壹仟万），全零节用「零」衔接低位节（壹亿零壹）
- **票据规范细节**：`10` → 壹拾（不写「拾」）；节内中间连续零只写一个；角位为 0 而分位非 0 补「零X分」；角分都 0 加「整」；整数为 0 时从角 / 分直接起头

## 已知取舍 / 暂不支持

- 只支持人民币（无外币、无「圆角分」之外的币种写法）
- 不支持「大写转数字」反向解析，只做数字 → 大写单向
- 不处理非标准写法（如古体「贰拾圆整」、发票专用章样式）
- 负数用前缀「负」，不提供括号 / 红字等票据负金额记法
