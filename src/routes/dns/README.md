# 公共 DNS · /dns

> 在线使用：<https://www.toolv.cn/dns> ・ 静态清单与命令模板，全程不联网、不上传

- **21 家公共 DNS 一页看完**：国内 10 家（阿里云、腾讯 DNSPod、114DNS 三个版本、百度、360 安全 DNS、CNNIC、清华 TUNA、中科大）+ 国外 11 家（Google、Cloudflare、Quad9、OpenDNS、AdGuard、DNS.SB、DNS.WATCH、Yandex、Comodo、Level3、Mullvad）
- **紧凑版式，一屏多看点**：一家一块，块内**一类地址占一行、主备并排**（`IPv4 223.5.5.5 ⧉ 223.6.6.6 ⧉`），不是「一个值一行」——21 家按后者要多滚近一半。说明文字压到 `leading-4`、块内边距 `py-2`，都是为了让扫读一屏能看到更多家
- **四类地址逐条可复制**：每家按 IPv4 → IPv6 → DoH → DoT 分组，**每个地址后面的按钮复制的是那一条**（不是整行、不是首列）；没有的类别不占位
- **每家附「配置页」链接，标签直接显示域名**（如 `www.alidns.com`、`sdns.360.net`）：新标签打开的是厂商**自己的服务地址 / 配置说明页**（列出了 IP 与怎么配的那一页），不是泛泛的厂商首页；配完可以点开核对一遍。链接目标是完整地址（含路径，如 360 的 `/dnsPublic.html`、Google 的 `/docs/using`），标签只显示主机名，一行放得下也一眼看出指向谁
- **查不到配置页的标「配置页未知」而不是隐藏**：CNNIC SDNS 与中科大没有公开的产品页，Comodo、Level3 两家资料太旧连官网都没能确认，这四行显示灰色「配置页未知」（鼠标悬浮有原因说明）；DNSPod 只找到产品首页、没有专门的公共 DNS 说明页，暂按首页收录
- **复制按钮紧贴地址、平时透明**：地址行是三段「类型 / 地址 / 复制」，复制按钮跟在地址值后面；**平时 `opacity-0`，鼠标停到那一行、或键盘聚焦到它时才现形**，触屏没有 hover 所以常显。走的 `opacity` 而不是 `display`，元素始终占位、可聚焦，显隐不会把地址挤一下；地址过长时先截断，`title` 里有完整值
- **按地区筛选**：全部 / 国内 / 国外三档分段选择
- **按关键词筛选**：一个搜索框同时命中**名称、说明、配置页链接与全部地址**（搜 `腾讯`、`223.5.5.5`、`拦截`、`adguard-dns.io` 都能用），空格分隔的多个词要**全部命中**
- **计数与空态分开**：头部计数念「命中 / 总数」，筛不到时念「无结果」并给专门的空态文案（与「清单本身是空的」区分）
- **一键重置**：同时把地区切回「全部」并清空搜索词；搜索词为空时按钮置灰
- **点行任意处 → 右侧命令自动换成这家**：整行可点（选中行浅蓝底、名字变蓝、行尾标「✓ 已选」），实现是一个铺满整行的透明按钮当背景层 + 内容层 `pointer-events-none`，只有地址、复制按钮、配置页链接抬回 `pointer-events-auto`；右栏另有下拉作为并行入口
- **右侧直接给「换 DNS」命令**：选系统（Windows / macOS / Linux）+ 设置成哪一家 + 填一次接口 / 服务 / 连接名 → 给出三条（Linux 四条）可逐条复制的命令：**① 查名字 ② 设置 ③ 还原**（Linux 另给 `systemd-resolved` 的临时改法）。命令是静态模板 + 把该家的 IPv4 主备与那个名字填进去，不联网、也不检测你有没有改成功
- **名字走输入框，留空回落样本值**：接口 / 服务 / 连接名各机器不同（Windows 还本地化），写死成默认名只能在一部分机器上碰巧可用，而让用户手改命令文本又很容易改坏引号。所以面板给一个输入框（标签跟着平台变：网卡名 / 网络服务名 / 连接名），**填一次 ②③ 一起更新**；留空时回落到该平台最常见的样本值（`WLAN` / `Wi-Fi` / `Wired connection 1`），不填也能复制即用
- **命令必带「查名字」与「还原」**：先给一条查明令让人把名字取回来；不给还原命令的话，用户不敢动全局 DNS
- **三个平台各自的坑写进面板**：Windows 要管理员、网卡名在中文系统上是「WLAN / 以太网」；macOS 要 `sudo`、填的是网络服务名（不是网卡名 `en0`）；Linux 没有统一命令、NetworkManager 持久而 `resolvectl` 重启就丢——都摆在提示里，不留在「你应该知道」
- **「为什么要换 DNS」同栏下方（好处与代价都列）**：好处 5 条（不吃解析插广告、调度更准、带过滤的能拦域名、DoH / DoT 加密查询、本地 DNS 抽风时的应急）+ **代价 4 条**（换了不保证更快、内网域名会解析不到、过滤类会误杀、加密 DNS 部分网络被阻断）。只讲好处等于劝人乱改，所以代价必须写
- **预渲染（prerender）**：整份清单在 SSR 的 HTML 里就渲染出来，利于 SEO 与首屏；筛选与复制在 hydration 后接管
- **只查不做**：不解析域名、不做延迟测速——也就**不发任何网络请求**

**没有建 `config.ts`**——按 `STRUCTURE §2 B` 的门槛，它只放「可调的业务数值与开关」，而这里没有可调的数值，只有一份数据清单。数据与参数都在同一个文件里：

## 档位

**L2**（`+page.svelte` + `core/store.svelte.ts` + `ui/*.svelte` 三个面板）：状态只有「地区 / 搜索词 / 命令面板的平台 / 命令面板的目标 / 命令面板填的那个名字（按平台各存一份）」五个字段，其余全是纯函数（`filterDnsProviders` / `addressEntries` / `groupAddresses` / `siteHost` / `validateDnsProviders` / `buildCommands` / `resolveInterfaceName`）。

怎么从 L1 升上来的：一开始只有一张列表（`ui/Panel.svelte`，L1）；加了「换 DNS 命令」与「为什么换 DNS」两张面板之后，一张变三张、`+page.svelte` 还要组装两栏，于是按 `STRUCTURE §0` 拆成 `ui/Workspace.svelte`（工具条 + 两栏布局，原来是那个 Panel 的上半截）+ `ListPanel` / `CommandPanel` / `WhyPanel` 各管一块。

## 数据口径

- **只收厂商自建的公共递归服务**，不收各省运营商自动下发的 DNS——那是按省份分配的，而且本机自动获取的那组通常更快，列出来只会误导。
- **`site` 优先指到「配置说明页」而不是厂商首页**：能配到这个服务的说明页就填它；只有确实找不到专门页时才退回产品首页（DNSPod 是退回首页的那一个）。
- 地址来自各厂商公开资料与公开汇总。**这类数据会变**——所以能核对的都附了配置页链接，页脚也写了这一句：配完自己点开核对一遍。
- **拿不准的字段一律留空，不猜**：OpenDNS 的 DoT、DNS.SB 的 IPv6 没收录（界面上只是少一行），查不到官方产品页的 `site` 也留空（界面上显示「配置页未知」）——比列一个错地址、挂一个假链接好。留空是**显式的缺口**：四个「配置页未知」就是四处还没查实的地方，别当成页面做漏了。
- 单测（`core/dns.test.ts`）除了结构校验，还按格式逐条查地址与链接：IPv4 四段且每段 0-255、IPv6 必须带冒号（挡「把 IPv4 抄进 IPv6 一栏」）、DoH 必须是完整 https 地址、DoT 必须是不带协议与路径的纯主机名、`site` 要么留空要么是合法 https 地址；另有锚点条目的写死断言（含每家官网指向对不对、以及哪几家该留空）。

## 实现口径

- **名字由输入框给，写死默认名这条口径已作废**：原先写死 `Wi-Fi` —— 它是**本地化显示名**，中文 Windows 上无线叫 `WLAN`、有线叫 `以太网`，于是默认状态下命令在多数中文机器上直接报「找不到适配器」（就是这么暴露出来的）。名字没法自动填对（各机器不同），但让用户手改命令文本同样会出错（引号很容易改坏），所以改成**填一次、②③ 一起更新**，留空回落样本值；`<占位符>` 仍然不写，因为粘进终端必然报错。第一步永远是「查名字」，查到后填进输入框。
- **Windows 用逗号分隔地址、`*nix` 用空格**：`-ServerAddresses` 收逗号，`networksetup` / `nmcli` / `resolvectl` 收空格，单测把这两条钉住了。
- **还原命令不带地址**（`-ResetServerAddresses` / `Empty` / 置空），别把「还原」误当成「设成别家」。
- **没有 IPv4 的服务返回空数组**，界面据此显示「生成不了命令」而不是拼出半条命令（当前 21 家都有 IPv4）。
- **右栏整体不滚**：命令面板里有下拉浮层（`absolute` 挂在卡片内），滚动容器会把它裁掉。滚动按「谁的内容会长谁自己滚」分配：**命令列表**与下面的**说明面板**各自滚，右栏本身不滚。不要给命令列表用视口单位做上限（`max-h-[40vh]` 那版已删）：它跟栏内实际余量无关，且滚动边界会把某条命令从中间截断。
- **命令块用 `break-words` 而不是 `break-all`**：前者只在空格处换行、长词才兜底断；后者会在任意字符处断，把 `223.5.5.5` 劈成「2」+「23.5.5.5」，看着像命令写错了。Linux 的命令最长（`nmcli` 那条 97 字符），这个问题在那一档最明显。
- **`label` 是给读屏的无障碍名，可见文字必须另给 children**：只传 `label` 会把「复制第 ① 查网卡名 条命令」这种长句子当成按钮文字显示出来。可见文字一律用 children 给（这里就是「复制」二字）；同时 `label` 要包含可见文字，以满足 WCAG 2.5.3（label-in-name）。
- **标签行：标签 `flex-1 min-w-0`、按钮 `class='shrink-0'`**，行内复制按钮 `size='xs'`（h-7）。按钮的文字档不带 `shrink-0`（只有图标档带），所以按钮得自己显式加。
- **选中态跨组件同步**：列表与命令面板读的是同一个 `store.commandTargetId`，所以「列表点行」与「面板下拉选择」天然一致。**筛选不影响目标**：把当前选中的那家筛掉了，命令面板照样给它生成命令。
- **整行可点的代价**：内容层是 `pointer-events-none`，所以行内的名称与说明文字不能拖选，但地址可以（地址自己抬回了 `pointer-events-auto`，顺带保住了截断时的 `title` 提示）。空白处点的都是那层铺满的按钮。
- 布局：`lg` 起两栏（右栏定宽 `24rem`），窄屏上下堆叠；窄屏下点服务名后命令面板在下方，行本身会高亮作为反馈。

## 已知取舍 / 暂不支持

- **延迟测速**：要给每家发一次 DNS 查询才能量延迟，跨域且需要服务端代发——与首页「数据本地处理」冲突。要做得先批一个新端点。
- **DoH 解析查询**：同上，浏览器直接请求第三方 DoH 端点会被 CORS 挡掉。
- **按省份的运营商 DNS**：见上面的数据口径——不是漏了，是不该列。
- **一键复制整家（四类一起）**：现在的复制单位是单条地址；要一次拿齐得再想清分隔格式，先不做。
- **直接帮你改（不自绘 GUI、不写注册表 / 配置文件）**：浏览器碰不到系统网络配置，只能给命令让你自己粘——而且改系统 DNS 本来就该由用户在自己的终端里确认。
- **自动检测你用的是哪种 Linux DNS 栈**：要看 `/etc/resolv.conf` 是不是符号链接、有没有 `resolvectl`，浏览器做不到，所以两条路线都列出、由用户自己认。

## 验证过什么

- `core/dns.test.ts`（server project，node 环境）：除结构校验（id 不重复、每家至少一条地址）外，按格式逐条查地址与链接——IPv4 四段且每段 0-255、IPv6 必须带冒号（挡「把 IPv4 抄进 IPv6 一栏」）、DoH 必须是完整 https 地址、DoT 必须是不带协议与路径的纯主机名、`site` 要么留空要么是合法 https 地址；另有锚点条目的写死断言（含每家官网指向对不对、以及哪几家该留空）。
- `core/commands.test.ts`：三个平台都要有「查名字」与「还原」、地址原样带上、Windows 逗号与 `*nix` 空格不混、没有 IPv4 时不给命令；另有名字那一组——留空 / 只有空白都回落到样本值、②③ 用的是同一个名字、Windows 样本值是 `WLAN`、带空格的名字三个平台都加了引号。
- 未做浏览器实测（axe / 几何量测条目无）。
