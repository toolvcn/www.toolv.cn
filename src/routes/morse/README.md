# 摩斯密码速查与加解密 · /morse

> 在线使用：<https://www.toolv.cn/morse> ・ 数据全部本地处理，不上传、不落库

- **双向实时转换**：文本 → 摩斯与摩斯 → 文本一个输入框搞定；点「互换」把输出搬回输入，来回验证不用手动复制
- **码表 54 条**：26 个拉丁字母 + 10 个数字 + 18 个标点，取 ITU-R M.1677-1
- **速查表可点插**：按 字母 / 数字 / 标点 分组，字符与摩斯码都能当关键词搜索；点一行按当前方向把字符 / 摩斯码插到输入框的光标处（解码方向会自动补一个字母分隔符，避免前后两个码连成一个更长的串），行尾一键复制摩斯码（搜索只筛渲染，不改数据）
- **不规范摩斯自动分词**：片段整体查不到码表时，按**字母表贪心最长匹配**自动切分 —— 少打几个空格也能读出词
- **宽容解析**：`·` `•` `—` `–` `_` 等点划变体照收；`/`、`|`、`\`、换行、制表、连续两个空格都当词分隔
- **点划与分隔符可自定义**：点 / 划可换成 `·` 与 `—` 等；字母分隔与词分隔各有一档常用写法（含「不分隔」，让整词自动分词）
- **失败可见**：编码时没有摩斯码的字符（中文、emoji 等）跳过并上报数量与字符；解码时解不出的片段**整体**标 `?` 并在底栏列出，不去猜半个词
- **整页预渲染**：码表与空态骨架都在 HTML 里，首屏可读，利于 SEO
- **面板全屏**：输入 / 输出卡片标题行各有一枚全屏按钮（原生全屏，Esc 退出）

## 实现口径

- **自动分词只认字母表**：`.` 与 `-` 各自都是合法字母码（E / T），所以任何点划串都能切完；
  把数字与标点放进来会先咬掉长的码 —— `......`（H + I）会先匹配 5 个点的数字 `5`，切成 `5E`
- **解码分两套切分规则**：默认符号下走宽容识别（`/` `|` `\` 换行 制表 连续两空格 = 词分隔，单空格 = 字母分隔）；
  **一旦自定义了分隔符就严格按它切**，两个口径混在一起用户没法预期
- **编码只出标准写法**：字母之间一个空格、词之间 `/`（或你选的那档）；无码字符直接跳过，整词都无码时不留空词
- **点划合法性**：点或划留空、或两者填成同一个字符时输出侧给错误态并停算 —— 同一串既可是点也可是划，解出来没有意义
- **速查表插入是纯计算**：`insertMorseEntry`（`core/morse.ts`）返回「插入后的内容 + 光标位置」，
  store 只落状态、组件只负责从 DOM 读选区再写回（同 `/regex` 速查表的做法，那边查的是 `<input>`，这里是 `<textarea>`）
- **解码方向才自动补分隔符**：编码插的是字符（字母之间本来就不需要分隔），解码插的是码 ——
  插在码后面时补一个字母分隔符，插在空白 / 斜杠 / 已设的分隔符后则不补；
  **只补前不补后**：中间插入是少数路径，补了会让「插完接着打字」落在分隔符前面

## 已知取舍 / 暂不支持

- **连写的摩斯不唯一**：`...---...` 既可以是 `SOS`，也能按最长匹配切成别的。自动分词是**启发式**、只当辅助，想准确就带上分隔符
- **不做音频播放**：摩斯播放要处理自动播放策略与播放队列，这轮不做（Web Audio 原生能做，留作后续）
- **不做扩展码表**：西班牙语的 `¿` `¡`、prosign（`SK`、`AR` 这类过程信号）都不收，只收 ITU 的字母 / 数字 / 标点
- **不区分大小写**：摩斯本身没有大小写，解码一律输出大写字母（编码时输入不分大小写）
- **不做整句语义纠错**：自动分词按贪心最长，不做词典或语言模型打分
