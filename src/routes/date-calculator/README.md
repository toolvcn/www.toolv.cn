# 日期计算 · /date-calculator

> 在线使用：<https://www.toolv.cn/date-calculator> ・ 数据全部本地处理，不上传、不落库

- **三个标签一页**：日期差 / 日期加减 / 工作日统计，各留各的状态，切换不丢输入。
- **日期差**：相差天数 + 含头含尾口径（请假、工期常用），约合周 / 满月 / 满年一次给全；结束早于开始按绝对值展示并提示。
- **日期加减**：加 / 减 天、周、月、年；「跳过周末」只按工作日推进（周五加 1 个工作日直接落到周一）。
- **月末钳制**：1-31 加一个月落在 2-28/29，不会静默滚进 3 月；2-29 加一年同理。
- **工作日统计**：区间内工作日 / 周末日 / 总天数（含头尾）；口径注明「周一到周五，不含法定节假日调休」。
- **解析严格**：`2026-02-31` 这类溢出日期直接判非法，不被 `Date` 静默进位；全部基于 UTC 正午计算，躲开时区与夏令时。
- **今天一键填**：日期框旁的「今天」按钮点击时才取本地日期，预渲染的 HTML 保持稳定。
- **结果可复制**：三个标签的结果各自一键复制（空 / 非法时给提示）。

## 参数在哪调

没有 `config.ts`——示例数据就近放在 `core/types.ts` 的 `EXAMPLES`（三个标签的默认起止日期与加减示例）。改默认示例动这一处；单位清单（`Unit`）与「跳过周末」开关也在这里。

## 档位

L2。编排在 `core/store.svelte.ts`（三个标签的输入、各 `$derived` 结果、复制 / 今天填充），纯函数在 `core/date.ts`（解析 / 差 / 加减 / 工作日统计），类型与示例在 `core/types.ts`；面板拆成 `ui/Workspace.svelte` + `ui/DiffPanel.svelte` / `ui/AddPanel.svelte` / `ui/BusinessPanel.svelte`，重复样式收进 `ui/styles.ts`。无服务端。

## 实现口径

- 全部基于 UTC 正午（12:00）计算：躲开时区偏移与夏令时把「差一天」算成「差 23 小时」的坑；解析只认 `YYYY-MM-DD`，溢出日期（如 `2026-02-31`）直接返回 null，不被 `Date` 静默进位到 3 月。
- 月末钳制：加一个月落在小月时夹到当月最后一天（1-31 → 2-28/29），加一年遇到 2-29 同理，不静默滚进下月。
- 工作日模式只对「天」有意义：其他单位下 UI 禁用「跳过周末」且计算强制忽略；跳过周末只按工作日推进（周五 +1 个工作日 → 周一），不把周末算进间隔。
- 工作日统计口径固定为「周一到周五」，不含法定节假日与调休（中国调休规则复杂，不内置日历）。
- 小数天数一律取整（`Math.trunc`），因为「半天」没有定义。

## 已知取舍 / 暂不支持

- 不含法定节假日 / 调休：工作日统计只按周一到周五，春节、国庆等调休日不识别。
- 不处理时区与具体时刻：只算日历日（`YYYY-MM-DD`），不含时分秒、不跨时区。
- 不做农历 / 节气 / 某年第几周等衍生计算。
- 不落库、无历史、无预设：刷新即空（除默认示例）。
