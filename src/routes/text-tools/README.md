# 文本统计与清理 · /text-tools

> 在线使用：<https://www.toolv.cn/text-tools> ・ 数据全部本地处理，不上传、不落库

- **多口径实时统计**：字符数（按 Unicode 码点，emoji 算 1 个）、非空白字符、字数（汉字 + 英文单词 + 数字串）、行数、非空行、段落数、UTF-8 字节，一张卡片一个口径，悬浮可见算法说明
- **行级清理流水线**：每行去首尾空白 → 删空行 / 合并连续空行 → 去重（保留首次出现）→ 按码点排序（升 / 降）→ 反转行序，勾选即生效、顺序固定可预期
- **只影响渲染不写回输入**：筛选与清理不动原始文本，点「写回」才把结果替换进输入框，方便叠加选项反复调
- **状态播报明确**：脚注实时说明「清理后输出 N 行 / 没有变化 / 没有剩余内容」，空态与无变化文案不重样
- 两个工作区页内标签切换，排序用码点比较（不用 `localeCompare`），跨平台结果稳定
- **面板全屏**：输入、统计结果与清理输出等卡片标题行各有一枚全屏按钮（原生全屏，Esc 退出）

## 参数在哪调

没有 `config.ts`，可调常量在 `core/types.ts` 与 `core/text.ts`：

- `STAT_ITEMS`：十张统计卡片的口径与悬浮说明（字符数 / 非空白字符 / 字数 / 中文汉字 / 英文单词 / 数字串 / 行数 / 非空行 / 段落数 / UTF-8 字节）
- `CLEAN_ITEMS`：清理选项的复选框标签与说明
- `EXAMPLE_STATS_INPUT` / `EXAMPLE_CLEAN_INPUT`：两个工作区的首屏示例
- `DEFAULT_CLEAN_OPTIONS`：清理开关的默认值（全关）；`EMPTY_STATS`：空文本的全 0 统计

## 档位

**L2**（+page.svelte + core/ 纯函数 + ui/ 面板）：`core/text.ts`（countTextStats / cleanText，一次性遍历）+ `core/store.svelte.ts` + `core/types.ts`。

## 实现口径

- **统计按 Unicode 码点**：字符数用 `[...text]` 展开（emoji 算 1 个，不是 2 个 UTF-16 码元）；字数 = 中文汉字 + 英文单词 + 数字串（连续数字算 1 个）；段落按空行（只含空白的行）分块
- **清理顺序固定可预期**：trim → 删空行 / 合并空行（删除优先于合并）→ 去重（保留首次出现，用 `Set`）→ 排序 → 反转；任一步都只依赖上一步输出
- **排序用码点比较**：`a < b ? -order : …`，不调 `localeCompare`（跨平台结果不稳定，单测没法断言）；反转在排序之后，不互相干扰
- **不写回输入**：清理结果只在渲染层显示，点「写回」才替换输入框，方便叠加选项反复调而不丢原文

## 已知取舍 / 暂不支持

- 字数是「汉字 + 英文单词 + 数字串」的近似口径，不按语言分词（如英文连字符词算 1 个词、CJK 扩展区字符不计入「中文汉字」）
- 不做大小写折叠去重（`A` 与 `a` 视为不同行）、不做按列 / 按字段的清理
- 不做「找重复并标出行号」「正则替换」这类高级编辑，那是 /regex 或专门的编辑器
- 大文本不做行数截断，清理对所有行生效（超长文本渲染性能由浏览器自身决定）

## 验证过什么

- `core/text.test.ts`：十口径统计（含 emoji 算 1 码点、空文本全 0、段落按空行分块）、UTF-8 字节、清理流水线各步与组合（删空行优先于合并、去重保留首次、码点排序、反转在排序后）、写回前后一致
- 浏览器实测：统计卡片悬浮说明、清理勾选实时预览、写回、两个工作区切换
