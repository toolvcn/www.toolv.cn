# 悬浮时钟 · 计时器 · /clock

> 在线使用：<https://www.toolv.cn/clock> ・ 数据全部本地处理，不上传、不落库

大字号数字时钟 + 倒计时 + 秒表三合一，重点在「摆着看」：颜色、字号、透明度随便调，背景可以全透明，小窗能置顶浮在别的软件上面。

- **四个模式一页**：时钟 / 倒计时 / 秒表 / 文字，各自留各自的状态，来回切不丢；**共用同一份外观配置**。
- **文字牌**：整块显示一段自定义文字（「会议中，请勿打扰」这类），当电子告示牌用——它没有任何专属外观，颜色、字体、描边、透明背景全部沿用共用的那一份。
- **背景可全透明**：背景色 + 不透明度滑块，拉到 0% 就是纯透明，给录屏 / 直播软件的浏览器源叠加用。
- **显示角度与翻转**：整块画面绕中心旋转，预设 0° / 90° / 180° / 270° + 任意角度滑杆，另有水平翻转（镜像）。90° / 270° 把画面长宽对调填满竖窗；其它角度按外接框缩一点，**保证不裁切**（长宽比纯 CSS 拿不到，由 `ResizeObserver` 量出交给 `rotateLayout` 算）。角度与翻转写进地址参数（`rot` / `flip`）：画中画即时跟着变，独立窗口的地址是快照——改完要重新打开或刷新那个窗口。
- **两种窗口形态**：
  - **悬浮窗**（画中画，Chrome / Edge 116+）：始终置顶、可自由拖拽缩放，这页改样式立刻同步；代价是寿命绑在工具页上——关掉工具页它也跟着关（浏览器规定，改不了）。
  - **独立窗口** `/clock/display`：有地址、能刷新、能收藏、能拖到副屏，关掉工具页也照样显示；**配置整份写在地址参数里**，能同时开好几个各显示各的，地址也能直接粘进 OBS 的浏览器源。
- **倒计时两个口径**：倒一段时长（开始 / 暂停 / 继续 / 重置）；倒数到每天某个时刻（过点自动滚到明天，不需要操作）。
- **到点行为**：默认停在 `00:00` 转红提示「时间到」；打开「超时正计时」后继续往上涨并标注「超时」。
- **秒表**：从 0 往上数，精度可切到十分之一秒 / 毫秒；不做计次。
- **打开就在跑**：倒计时与秒表进页面自动开始，不用先点「开始」；**刷新即新的一轮**（计时进度刻意不落盘——落盘的只有样式与选项这类「设置」）。

## 独立窗口 `/clock/display`

可以**单独使用**：直接粘到浏览器里就是一个纯时钟页（无导航、无面板），能收藏、能拖到副屏。

**配置只来自地址参数**——地址是那份窗口的唯一真值：不读 localStorage，也不跟着别的窗口变。这样一份地址自带一份配置：可以同时开好几个窗口各显示各的（一个时钟 + 一个倒计时）；地址能收藏、能发给别人、能**直接粘进 OBS 的浏览器源**（那边是另一个浏览器 profile，够不着本站的存储）；换个浏览器、换台机器也显示成同一个样子。

- 工具页的「打开独立窗口 / 复制地址」生成的是**全量参数**地址，所以打开就和工具页一致；
- 手写地址时只写想改的项即可——没写的项用默认值（`config.ts` 里的默认常量），于是裸地址 `/clock/display` 就是一个默认样式的时钟。

| 参数                            | 取值                                         | 含义                                             |
| ------------------------------- | -------------------------------------------- | ------------------------------------------------ |
| `mode`                          | `clock` / `countdown` / `stopwatch` / `text` | 显示哪个模式（四个模式在展示页里都成立）         |
| `bg` `fg`                       | 六位十六进制，**不带 `#`**                   | 背景色 / 文字色                                  |
| `alpha`                         | `0`-100                                      | 背景不透明度，0 即全透明                         |
| `size`                          | `auto` 或 24-360                             | 字号：自动填满 / 固定像素                        |
| `pad`                           | `0` `2` `4` `6` `8`                          | 内边距档                                         |
| `font`                          | `mono` / `sans` / `serif`                    | 字体                                             |
| `weight`                        | 400-900                                      | 字重                                             |
| `outline`                       | `none` / `soft` / `strong`                   | 描边                                             |
| `rot`                           | `0`-359                                      | 显示角度（度），整块画面绕中心旋转               |
| `flip`                          | `0` / `1`                                    | 水平翻转（镜像）                                 |
| `h12` `sec` `week` `tz` `blink` | `0` / `1`                                    | 12 小时制 / 显示秒 / 星期 / 时区 / 冒号闪烁      |
| `date`                          | `none` / `iso` / `cn`                        | 日期格式                                         |
| `cd`                            | `duration` / `daily`                         | 倒计时口径                                       |
| `dur`                           | 秒数，也认 `30m` / `1h30m`                   | 时长型倒计时的时长                               |
| `at`                            | `20:00` 或 `20:00:30`                        | 时刻型倒计时的每日目标                           |
| `over`                          | `0` / `1`                                    | 到点后是否转成超时正计时                         |
| `prec`                          | `sec` / `tenth` / `ms`                       | 秒表精度                                         |
| `prefix`                        | 文本                                         | 前置文案，按 `mode` 落到倒计时或秒表那一份上     |
| `text`                          | 文本                                         | 文字模式要显示的内容，可含换行（超长按上限截断） |
| `align`                         | `center` / `left`                            | 文字模式的对齐                                   |

认不出来的值一律**当作没写**（回落到本地配置），不会被静默纠正成别的值——写错一处不会把整个地址带偏。

## 参数在哪调

业务参数全部在根层 `config.ts`（不在 `core/` 下）：默认样式 `DEFAULT_STYLE`、配色预设 `STYLE_PRESETS`、字体栈 `FONT_STACKS`、字号与内边距档位（`FONT_SIZE_RANGE` / `PADDING_STEPS`）、小窗尺寸档与窗口名（`WINDOW_SIZES` / `WINDOW_NAME`）、走时间隔 `TICK_MS`、存储键 `STORAGE_KEY`、倒计时的上限与快捷分钟档（`DURATION_RANGE` / `QUICK_MINUTES`）、前缀文案长度上限 `PREFIX_MAX_LENGTH`。改数值先看它。

## 档位

L2：四个标签 + 预览区 + 六个设置面板（外观 / 时钟 / 倒计时 / 秒表 / 文字 / 窗口），外加一个展示页 `/clock/display`。编排在 `core/store.svelte.ts`（三个模式的选项、计时状态、显示样式、本地持久化），显示字符串拼装在 `core/format.ts`，地址参数编解码在 `core/params.ts`，类型在 `core/types.ts`；面板拆成 `ui/Workspace.svelte` + 六个设置面板组件 + `ui/ClockStage.svelte`（被搬进小窗的节点）+ `ui/window.ts`（开窗逻辑）。独立窗口是 Routes 下的子路由 `display/`，不归在本目录的 `ui/` 里。

## 实现口径

**不做「每秒加一」，只存「目标时刻 / 起点 + 累计里程」，每次读的时候用当前时刻换算**：

- 标签页切到后台时浏览器会把 `setInterval` 节流到大约 1 次/分钟，累加法半小时能差出好几分钟；
- 存时间戳的算法任何时候读出来都对，切标签、卡顿都不影响它。

**计时进度不落盘**：`PersistedData` 里只有「设置」（模式、样式、四个模式的选项、窗口尺寸）。打开页面自动开一轮（`startNewRound`），刷新即新的一轮——不会出现「昨天设的 30 分钟、今天打开还在倒」。细节在 `core/store.svelte.ts` 文件头注释与 `core/format.ts` 的三条约定里。

## 刻意不统一

1. **`ui/ClockStage.svelte` 一处 Tailwind class 都不用**，全部 inline style。小窗是把该节点**整体搬进另一个 document** 的，那边没有本站的样式表——用 class 写会在窗口里整块失灵；而且时钟是一幅独立画面，不该跟着站点的深浅主题走。改样式请继续内联。
2. **色板（`input[type=color]`）的样式在 `ui/AppearancePanel.svelte` 里又写了一份**，与 color-converter 的 `ui/styles.ts` 的 `SWATCH` 重复。目前只有两处，提升要动全站共享的 `$lib/ui/styles.ts`，等第三处出现再提。

## 已知取舍 / 暂不支持

- **秒表不做计次（lap）**：只给累计时长，不记每一圈——定位是「看跑了多久」，不是分段分析。
- **不连 NTP / 不校准时间**：走系统时钟，系统时间不准时钟就跟着不准（计时相对值不受影响）。
- **画中画仅桌面端 Chrome / Edge 116+ 支持**：不支持的浏览器自动降级为打开独立窗口；移动端没有画中画。
- **独立窗口配置只来自地址参数**：故意不读 localStorage、不跟着工具页实时变（快照语义），所以工具页改完要重新打开或刷新那个窗口才生效。
- **文字模式没有专属外观 / 动画**：一切沿用共用外观配置，不另做一套。

## 验证过什么

- 纯逻辑单测在 `core/format.test.ts` 与 `core/params.test.ts`（server project，node 环境）：`format` 覆盖时钟 / 倒计时 / 秒表的显示字符串、取整口径（倒计时剩余向上取整、秒表向下取整）、日期与星期格式；`params` 覆盖独立窗口地址参数的编解码、默认值回落、认不出的值当没写。
- 未做浏览器实测（画中画 / 全屏 / 旋转这类依赖真实窗口与渲染的，无 axe / 几何量测条目）。
