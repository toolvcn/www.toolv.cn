# 命名风格转换 · /case-converter

> 在线使用：<https://www.toolv.cn/case-converter> ・ 数据全部本地处理，不上传、不落库

- **七种风格一次列出**：camelCase / PascalCase / snake_case / kebab-case / CONSTANT_CASE / Title Case / 小写空格，输入一处、七行结果逐行复制；每行附常用场景说明（选起来不纠结）。
- **自动分词**：下划线、短横线、空格、标点都是分隔符；`myVar` 按驼峰边界拆，`parseHTTPResponse` 识别缩写拆成 HTTP + Response，`v2` / `base64` 这类字母数字组合保持完整。
- **中文安全**：中文整体当一个词参与连接，不会被逐字误拆。
- **输入即转**：无需点按钮，纯本地计算，改一字七行结果实时重算。
- **逐行复制 / 示例 / 清空**：每行结果一键复制（空时给提示）；默认填入示例标识符，也可一键清空。
- **输入计数**：输入字符数常驻面板头部。

## 参数在哪调

没有 `config.ts`——风格清单与示例就近放在 `core/types.ts`：`CASE_STYLES`（七种风格的定义、标签、示例、场景）、`EXAMPLE_INPUT`（默认示例 `parse HTTPResponse_2s-delay`）。改风格种类或换示例动这一处。

## 档位

L2。共享状态在 `core/store.svelte.ts`（输入、`$derived` 七行结果、复制 / 示例 / 清空操作），分词与转换在 `core/case.ts`（纯函数），类型与常量在 `core/types.ts`；面板拆成 `ui/Converter.svelte`。没有 `ui/styles.ts`。

## 实现口径

- 分词按书写边界，不依赖语言词典：非字母数字（`_` `-` 空格、标点）都是分隔符；小写 / 数字 → 大写的边界断词；连续大写缩写在「大写 → 大写 + 小写」处断词（`HTTPResponse` → `HTTP` `Response`）；字母与数字交界不断词（`v2` / `base64` 保持完整），中文按 Unicode 字母整体成词。
- 不要求选「来源风格」：统一拆词再按目标风格重组，所以任意混合写法都能正确转去，不需要先声明它本来是什么风格。

## 已知取舍 / 暂不支持

- 不做语义 / 关键字级分词：只认书写边界，不认语言关键字（如 `int` 不会被特殊对待）。
- 不做「按某语言惯例反向推导来源风格」这类双向标注，定位就是「输入任意命名、一键看七种写法」。
- 不落库、无历史、无预设：刷新即空（除默认示例）。

## 验证过什么

- `core/case.test.ts`（server project，node 环境）覆盖：分词（分隔符全断词、驼峰边界、缩写断词、字母数字组合保持完整、中文整体成词、空串与纯分隔符）、七种风格转换（首词小写、缩写也不例外、中文只变连接不变形、空输入结果为空）、store（实时七行、示例填充 / 清空、空行复制给提示、复制成功 / 失败）。
- 未做浏览器实测（无 axe / 几何量测条目）。
