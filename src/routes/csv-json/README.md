# CSV ↔ JSON 转换 · /csv-json

> 在线使用：<https://www.toolv.cn/csv-json> ・ 数据全部本地处理，不上传、不落库

- **双向实时转换**：CSV → JSON 与 JSON → CSV 两个标签各自保留输入，切换不丢内容；粘贴即转，不用点按钮。
- **RFC 4180 完整解析**：引号字段内可放分隔符与换行，`""` 转义还原；序列化时需要加引号的字段自动包裹，来回转换不坏数据。
- **分隔符可换**：逗号（RFC 4180）、分号（欧式 Excel）、Tab（表格软件粘贴）、竖线（日志导出）四种。
- **值类型可推断**：`42`、`-3.5` 自动转数字；`true` / `false` / `null` 转对应字面量；`007`、`1e5` 这类有歧义的保持字符串，空串忠实保留。
- **表头灵活**：CSV 侧可关表头（输出二维数组），空表头与重复表头自动补 `colN` / 加序号；JSON 侧对象数组取键并集当列、缺键留空，嵌套对象 / 数组转 JSON 文本。
- **复制与下载**：一键复制，或直接下载 `data.json` / `data.csv`；纯本地解析，无任何依赖。
- **面板全屏**：输入 / 输出卡片标题行各有一枚全屏按钮（原生全屏，Esc 退出），大表单独铺满屏幕看。

## 实现口径

- 解析是 RFC 4180 状态机而不是 `split`：引号字段里能放分隔符与换行，`""` 转义成一个引号；序列化时字段含分隔符 / 引号 / 换行才加引号，内部引号双写，行尾统一 `\r\n`——保证往返一致。
- 类型推断边界：`007`、`1e5` 这类「像数字但有歧义」的保持字符串（否则 `007` 会变 `7` 丢前导零）；`null` / `true` / `false` 转字面量，空串保持空串（比当成 null 更忠实）。
- 表头归一化：空表头补 `colN`、重复表头加 `_2` / `_3` 后缀；关表头时输出二维数组，列数取最宽一行、短行右侧补空。
- JSON → CSV 接受对象数组（所有键按首次出现顺序并集当列、缺键留空）或二维数组；嵌套对象 / 数组转 JSON 文本；根不是数组、或元素类型混杂（对象与数组混排）直接报错并给中文说明。

## 已知取舍 / 暂不支持

- 不做流式 / 分块解析：整段文本读进内存再算，超大 CSV 受浏览器内存限制（具体上限随运行环境）。
- 不做 YAML / XML 等其它格式互转：那是别的工具的事。
- 不做数据清洗 / 去重 / 校验 / 排序：定位是「格式互转」，不是表格编辑器。
- 不落库、无历史、无预设：刷新即空（除默认示例）。

- `core/csv.test.ts`（server project，node 环境）覆盖：解析（引号内分隔符 / 换行、`""` 转义、尾随换行不产空行）、序列化（需要时加引号、内部引号双写）、类型推断（数字 / 布尔 / null / 歧义字符串 / 空串）、表头归一化（空与重复）、JSON → CSV（对象数组键并集、二维数组、嵌套转文本、非法输入报错）、双向往返。
