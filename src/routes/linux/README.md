# Linux 命令速查 · /linux

> 在线使用：<https://www.toolv.cn/linux> ・ 数据全部本地处理，不上传、不落库

- **九类命令按组列出**：文件与目录 / 查找与搜索 / 查看与编辑 / 文本处理 / 权限与属主 / 进程与作业 / 系统与资源 / 网络与传输 / 压缩与归档，共 66 条；分组 chips 单选用 `aria-pressed`，默认停在「全部」（整张表都在 SSR 的 HTML 里），点「常用」只看 23 条高频命令
- **填一次变量，全部命令跟着变**：`{{path}}` 这类占位符由变量条统一替换；**你填的值加淡绿底**（一眼看出哪几个是自己填的），留空回落示例值的只有绿字。目标路径常驻工具条，「更多变量」（文件名 / 关键词 / 端口 / 主机 / 用户 / 服务名 / 源路径 / 压缩包名 / 天数 / 进程号）收在折叠区
- **留空回落到示例值**：输入框空着时命令用示例值（`/var/log` / `app.log` / `nginx` / `8080`），所以**不填任何东西也能直接复制即用**，命令里不会残留 `{{...}}` 原文；「重置」把全部输入清空回到示例值
- **备选写法 chips**：`sed -i` ↔ 只预览不落盘、`tail -f` ↔ `tail -F`、`rm -rf` ↔ 先 `ls -ld` 看一眼、`ss -tulnp` ↔ 过滤某个端口、`scp` ↔ `rsync`（可续传）、`tar xzf` ↔ 解到指定目录 等；下标 0 是主模板，第一个 chip 是「默认」
- **危险命令标注**：`rm -rf` / `find -delete` / `sed -i` / `pkill -f` 共 4 条给红或琥珀徽章 + 悬浮说明。**只标注、不弹窗确认** —— 复制的只是文本，真正执行在用户自己的机器上
- **代价写进 note**：危险命令必须在 `note` 里说清后果（「不可恢复、不进回收站」「`-i` 是原地修改，改错了没有撤销」「匹配太宽会把当前 ssh 会话一起杀掉」），体检单测会拦住没写 note 的危险命令
- **检索口径**：命令本体、中文说明、英文子命令与分组名都参与匹配（输 `端口占用`、`磁盘满了`、`解压`、`less` 都能命中）；筛选只影响渲染，不写回数据
- **复制**：每条**行首**一个图标按钮，一键复制渲染后的完整命令（按钮统一在左侧，命令起始位置因此也整齐）
- **参数预设（左栏）**：在变量条里填好路径 / 文件名 / 服务名等参数，起个名字点「保存」就存在本地（`localStorage`，刷新与重开都在），点条目一键回填**整个变量条**、所有命令跟着变；悬浮条目逐条删除，标题行可导出 / 导入 JSON 备份（与 http 请求调试、电商 ROI 同一套面板）
- **版式：左右双栏 —— 左栏「变量条在上、预设面板在下」，右栏命令列表**：宽屏（lg 起）走 ToolShell 的 `fill` **满屏**，两栏各占视口高度、各自内部滚；变量条展开时滚的是左栏，不会把命令列表顶下去、也不会把预设面板压扁。栅格收在共享的 `CommandCheatsheet` 组装件里（docker / git / linux 同一套），左栏 `22rem` 是下限（再窄「更多变量」的网格只剩一列、10 个变量拖成 10 行）。小屏退回自然流单列：变量条 → 预设 → 命令列表
- **「更多变量」展开是自适应网格**（每列至少 `9rem`，共享 `VarBar`）：写死 3 列时 10 个次要变量占 4 行、右半边还空着；自适应后在 22rem 左栏里排 **2 列**
- **一条预设只存「填了值的变量」**：留空的变量不存 —— 保存时一个都没填会被拦下（存下来跟示例值一样）；回填是**完整快照**，没存过的变量一律清空、回落示例值，而不是往当前输入上叠。分组筛选 / 搜索词 / 备选写法**不进预设**（那是「当前在看什么」，不是「这套参数」）
- **别的花括号原样保留**：`date +%s`、`%{http_code}` 这类不属于本页变量，替换时按「键名不认识就整段跳过」处理，不用转义
- **SSR 首屏有货**：命令与分组在构建期就写进 HTML，打开即可读（`+page.ts` 开了 `prerender`）

## 参数在哪调

占位符的键名、中文标签与默认示例值都在根目录 `config.ts`（`VAR_DEFS`）。
要改示例值（换成自己机器上的路径 / 服务名）、加一个新变量（比如 `{{iface}}`），改这一份即可 ——
store 取它的 `sample` 当初始值与留空时的回落值，变量条取 `label` / `hint` 渲染输入框，
并按 `secondary` 决定哪些收进「更多变量」。分开写迟早出现「改了示例值、输入框提示没变」。

**参数预设的 `localStorage` 键**也在 `config.ts`（`PRESETS_STORAGE_KEY` = `toolv:linux-presets`）。
持久化本身写在 `+page.svelte`（挂载时恢复、之后每次改动写回，带 `restored` 开关防止首帧空值覆盖），
面板逻辑在共享的 `CheatsheetStore`（`savePreset` / `applyPreset` / `deletePreset` / `restorePresets` /
`importPresetsText`）与 `$lib/components/PresetPanel`，序列化 / 解析纯函数在
`$lib/utils/command-cheatsheet`（`serializeCheatsheetPresets` / `parseCheatsheetPresets`）。
本工具的 `ui/PresetPanel.svelte` 只做业务绑定（idPrefix、导出文件名、徽章与摘要文案、空态）。

与 `config.ts` 的边界：**命令数据与分组在 `core/commands.ts`**；占位符替换、分词、搜索、分组、预设序列化与数据体检的
纯逻辑在 `$lib/utils/command-cheatsheet`，界面在 `$lib/components/CommandCheatsheet`（见下）。
本工具自己的 `core/` 只放数据、store 与体检单测。

## 档位

**本工具目录内是 L1**：`config.ts`、`core/commands.ts`（数据）、`core/store.svelte.ts`（拿数据 new 出共享编排类）
与 `core/commands.test.ts`；`+page.svelte` 做 ToolShell + SEO head + 组装 + 预设持久化；
`ui/PresetPanel.svelte` 是预设面板的业务绑定（这一层是本工具独有）。

界面与纯逻辑**不在本目录**：docker / git / linux 三个命令速查工具共用
`$lib/components/CommandCheatsheet`（`CommandCheatsheet` 组装件 —— 双栏栅格就在它里面，
预设面板由各工具用 `presets` snippet 传进去、`VarBar` 变量条、`CommandList` 命令列表
与 `cheatsheet.svelte.ts` 里的 `CheatsheetStore` 编排类）和 `$lib/utils/command-cheatsheet`
（`resolveVars` / `tokenizeCommand` / `filterCommands` / `groupCommands` / `validateCheatsheetData` /

再加一份预设面板的业务绑定。所以本工具目录里**没有 `core/types.ts`**：类型定义随共享层走，不在这里再抄一份。

## 刻意不统一

- **不做危险命令的二次确认弹窗**：与 regex 删除已保存配置时的确认弹窗不同 —— 那边删的是本机数据，
  这边只是复制一段文本，确认弹窗拦不住任何后果，只会给高频操作添噪音。
- **变量条用「留空 = 回落示例值」而不是禁用复制**：命令永远处于可复制状态，
  要比「没填就禁用复制按钮」更顺手，也避免用户对着灰按钮猜该填什么。
- **预设不做拖动排序**（面板支持，本工具没接 `onreorder`）：条目按保存顺序排，够用；
  电商 ROI 接它是因为要按口径分组对比，与这里「给几个自己常用的路径 / 服务名」不是一回事（http 也没接）。

## 数据口径

- **只收通用发行版都有的命令**：`systemctl` 这类 systemd 专属的会注明「老系统用 `service`」，
  `ip` 会注明 `ifconfig` 属已废弃的 net-tools，`zip` / `jq` / `lsof` 会注明需另外安装 —— 不默认用户装了什么。
- `note` 记的是**坑与代价**，不是复述命令：如「`uniq` 只合并相邻重复、前面必须先 `sort`」
  「`wc -l` 数是换行符个数，末行没换行时会少 1」「`tail -f` 遇到日志轮转会跟丢，得用 `-F`」，
  都是排查时最容易踩的那几条。
- 每条模板都是**可直接粘进 shell 的完整命令**，不留「这里你自己补」的空档（变量也都有示例值兜底）。

## 实现口径

- **占位符只替换认得的键**：变量条按 `VAR_DEFS` 的键替换 `{{path}}` 这类占位符，「键名不认识就整段跳过」——`date +%s`、`%{http_code}` 这类别的花括号原样保留，不用转义
- **留空回落示例值**：输入框空着时用 `sample`（淡绿底的是用户填的值，纯绿字的是回落的示例值），命令里不残留 `{{...}}`；「重置」把全部输入清空回到示例值，所以不填任何东西也能直接复制即用
- **搜索多字段 OR**：命令本体、中文说明、英文子命令与分组名都参与匹配；筛选只影响渲染，不写回数据
- **预设是完整快照**：一条预设只存「填了值的变量」，留空的变量不存（全空会被拦下）；回填是完整快照，没存过的变量一律清空、回落示例值，而非往当前输入上叠；分组筛选 / 搜索词 / 备选写法不进预设
- **危险命令强制写 note**：`rm -rf` / `find -delete` / `sed -i` / `pkill -f` 共 4 条给红或琥珀徽章 + 悬浮说明，且必须在 `note` 里说清后果（数据体检单测会拦住没写 note 的危险命令）

## 已知取舍 / 暂不支持

- **只查阅、不执行**：页面复制的是文本，真正执行在用户自己的机器上，故不做「一键跑命令」也不做危险命令的二次确认弹窗（确认拦不住任何后果，只给高频操作添噪音）
- **不覆盖 docker / git 之外的运行时语义**：命令按通用 shell 语义写，不与特定发行版、桌面环境、容器编排绑定
- **不保证覆盖你机器上的别名 / 函数 / alias**：模板是裸命令，用户自己的 shell 别名优先级更高
- **备选写法只给常见可替代项**：`sed -i` ↔ 只预览不落盘、`scp` ↔ `rsync` 等，不做穷尽的所有等价写法枚举
