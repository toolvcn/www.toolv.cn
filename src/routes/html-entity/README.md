# HTML 实体编解码 · /html-entity

> 在线使用：<https://www.toolv.cn/html-entity> ・ 数据全部本地处理，不上传、不落库

一个输入框搞定命名实体与数字实体的互转 —— 点「互换」把输出搬回输入，来回验证。

- **双向实时转换**：文本 → 实体与实体 → 文本同一输入框，方向切「编码 / 解码」，输出实时派生；点「互换」把当前输出搬回输入
- **转义范围可调**：仅必需字符（`& < > " '`）/ 含常用符号（©、™、箭头、希腊字母等）/ 所有非 ASCII
- **实体形式可调**：命名实体优先（`&copy;`），没有名字的退回数字实体；也可一律十进制数字实体（`&#169;`）
- **解码宽容**：未知命名、缺分号、超界码点一律原样保留，坏实体不拖垮整段，与浏览器 DOM 解析行为一致
- **中文与 emoji 安全**：按真实 Unicode 码点转换，emoji 一次转成单个数字实体，代理对不拆散
- **内置约 130 个高频命名实体**，解码支持十进制 / 十六进制（`x` 大小写不限）
- **复制**：一键复制输出结果（纯文本）
- **SSR 首屏有货**：预渲染的示例文本与结果在 HTML 里可见
- **面板全屏**：输入 / 输出卡片标题行各有一枚全屏按钮（原生全屏，Esc 退出）

## 参数在哪调

**没有 `config.ts`**：业务参数只有首屏示例文本（`EXAMPLE_TEXT`）、三个枚举类型（编码范围 `EncodeScope` / 实体形式 `EncodeStyle` / 方向 `EntityDirection`）与约 130 个命名实体表，都就近放在 `core/types.ts` 与 `core/entities.ts` —— 没到「同一个数散在 `core/` 与 `ui/` 两边」的门槛，按 `STRUCTURE §2 B` 就地放着。

## 档位

**L2**：`core/`（纯函数 `entities.ts` + `types.ts` + `store.svelte.ts` 编排）+ `ui/`（`Converter` 面板）。没有 `ui/styles.ts`（没有同一串样式出现两处的地方，样式走 `$lib/ui/styles` 与 Tailwind）。

## 实现口径

- **先 UTF-8 编码再处理**：文本一律按真实 Unicode 码点转换，中文 / emoji 不会被当多字节拆坏；emoji 的代理对当一个码点，转成单个数字实体，不会散成两半。
- **解码宽容**：未知命名实体、缺分号、超界码点一律原样保留并继续往下走，与浏览器解析一致 —— 不丢字符、不报错、不拖垮整段。
- **命名优先时查不到名字的码点退回数字实体**：保证编码 → 解码可无损往返，不会因为「没收录这个名字」就丢信息。
- **编码范围三档各自独立**：`required` 只转五个必需字符，`symbols` 加常用符号，`nonAscii` 把所有非 ASCII 一并转，互不重叠。

## 已知取舍 / 暂不支持

- **不做批量文件转码**：只处理文本框，不读本地文件；大段 HTML 粘进文本框即可，但没有「拖文件进来」。
- **不收全部 HTML5 命名实体（约 2000+）**：只内置约 130 个高频命名实体，查不到的一律走数字实体（无损，只是长了点）。
- **不校验「实体在上下文里会不会被当成标签」**：用户自己保证粘贴位置的语义。

## 验证过什么

- `core/entities.test.ts`：命名 ↔ 数字实体往返、编码范围三档边界、宽容解码（坏实体原样保留）、emoji 代理对单一实体、十六进制大小写。
- 浏览器实测：375 / 1280 无横向溢出，axe 0 violations；SSR 首屏示例与结果在 HTML 里可见。
