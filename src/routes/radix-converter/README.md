# 进制转换 · /radix-converter

> 在线使用：<https://www.toolv.cn/radix-converter> ・ 数据全部本地处理，不上传、不落库

- **五种进制实时互转**：输入进制可选 2 / 8 / 10 / 16 / 36（也认 `0x` / `0b` / `0o` 前缀），输出同步列出全部进制、逐行复制
- **BigInt 精确运算**：任意大整数不丢精度（64 位以上的哈希 / ID 都能转），支持负号、大小写混写、下划线分隔
- **字母输出默认大写，可切小写**

## 参数在哪调

没有 `config.ts`，可调常量都在 `core/types.ts`：

- `OUTPUT_BASES = [2, 8, 10, 16, 36]`：输出逐行列出的进制顺序
- `SOURCE_BASES`：输入进制下拉选项
- `BASE_LABEL`：各进制的展示名（二进制 / 八进制 / 十进制 / 十六进制 / 三十六进制）
- `RADIX_DIGITS = '0123456789abcdefghijklmnopqrstuvwxyz'`：0-35 的字符表，解析与格式化共用

## 档位

**L2**（+page.svelte + core/ 纯函数 + ui/ 面板）：`core/radix.ts`（parseRadix / formatRadix / autoDetect 全程 BigInt）+ `core/store.svelte.ts` + `core/types.ts`。

## 实现口径

- **全程 BigInt，不碰浮点**：任意大整数精确互转，64 位以上的哈希 / ID 不丢精度；解析允许前导正负号、字母大小写混用，空白与下划线忽略（如 `1_000_000`）
- **前缀自动识别**：`0x` / `0b` / `0o` 前缀一并接受，自动切到对应进制；无前缀默认十进制
- **大小写只影响展示**：解析统一转小写，输出字母默认大写、可切小写，不影响数值

## 已知取舍 / 暂不支持

- 不做小数 / 浮点进制转换，只处理整数（BigInt 本身无小数）
- 不收 36 进制以上的自定义字母表（如 base62），输出进制固定五档
- 非法字符（超出当前进制的数字）直接报「无法解析」，不在内部猜测进制
