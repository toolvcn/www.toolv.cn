# 哈希计算 · /hash-calculator

> 在线使用：<https://www.toolv.cn/hash-calculator> ・ 数据全部本地处理，不上传、不落库

- **五种算法一屏看完**：MD5 / SHA-1 / SHA-256 / SHA-384 / SHA-512 逐行列出，输入即算、逐条结果独立复制
- **MD5 自实现**：WebCrypto 的 `subtle.digest` 刻意不提供 MD5（已可碰撞），这一支是本地自写的纯函数（`core/md5.ts`），实现比引包可控，且**不依赖 WebCrypto** —— 非 HTTPS 环境下 SHA 系列算不出来时 MD5 仍可用
- **「已不安全」标注**：MD5 与 SHA-1 两行标出提示（两者都被公开证明可构造碰撞），避免当成签名 / 口令用途 —— 只适合做兼容校验；SHA-256 / 384 / 512 不标
- **纯 WebCrypto（其余四种）**：`crypto.subtle.digest` 本地计算，内容不出浏览器；结果大小写可切
- **竞态兜底**：连打多下只认最后一次输入的结果，晚到的旧摘要直接作废
- **字符数与 UTF-8 字节数实时显示**，便于确认「算的是多大一段」
- **面板全屏**：输入与结果卡片标题行各有一枚全屏按钮（原生全屏，Esc 退出），长摘要单独铺满屏幕看

## 参数在哪调

**没有 `config.ts`**：算法清单（`ALGORITHMS`）、各算法位数（`HASH_BITS`）、是否标注「已不安全」（`isInsecure`）在 `core/types.ts`；首屏示例文本（`EXAMPLE_TEXT`）在 `core/hash.ts`。这些都是少量常量，没到「散在 `core/` 与 `ui/` 两边」的门槛，按 `STRUCTURE §2 B` 就地放着。

## 档位

**L2**：`core/`（纯函数 `hash.ts` + 自实现 `md5.ts` + `types.ts` + `store.svelte.ts` 编排，含 `hash.test.ts` / `md5.test.ts`）+ `ui/`（`Panel` 结果面板）。

## 实现口径

- 文本一律**先 UTF-8 编码再哈希**，中文 / emoji 与文件哈希口径一致（`core/hash.ts` 的 `hexDigest`）。
- 摘要输出用 64 位小端位长补齐，MD5 的结果按小端拼十六进制（不能直接 `toString(16)`）。
- 摘要计算是异步的（subtle.digest 返回 Promise），用自增序号只认最后一次发起的，旧的晚回来就丢弃，保证结果跟得上输入。

## 踩过的坑

- **MD5 的常量表（`K[i]`）与位移表写死字面量，别改成 `Math.sin` 现算** —— 现算在边界上差 1 会静默算错。

## 已知取舍 / 暂不支持

- **不做文件 / 大文件流式哈希**：现在只有文本框输入；大文件要分块读、增量更新，属于另一套界面（也涉及大内存与进度），本轮不收。
- **MD5 只用于兼容校验**：标了「已不安全」，不做口令哈希 / 签名（那该用专门的 KDF / 签名算法，不在本页）。
- **不做「加盐哈希」「HMAC」**：要的是原始摘要，不是消息认证。

## 验证过什么

- `core/md5.test.ts`：RFC 1321 的 7 条标准向量 + 用 `node:crypto` 当对照跑补齐边界（55 / 56 / 64 这类边界只靠短字符串测不出来）。
- `core/hash.test.ts`：UTF-8 编码后哈希与 `node:crypto` 对照、大小写切换、空输入为空串。
- 浏览器实测：375 / 1280 无横向溢出，axe 0 violations；SSR 首屏示例文本在 HTML 里可见。
