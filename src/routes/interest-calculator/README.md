# 利率计算器 · /interest-calculator

> 在线使用：<https://www.toolv.cn/interest-calculator> ・ 数据全部本地处理，不上传、不落库

- **贷款与存款一页两套**：顶部「算什么」切贷款 / 存款，三个数值（金额、年利率、期限）共用，
  下面两块面板跟着换成「月供 / 还款计划」或「到期本息 / 逐年明细」
- **等额本息**：每月月供固定，给月供、还款期数、支付利息总额、本息合计
- **等额本金**：首月月供、末月月供、每月递减额各一行，其余同上；
  结果卡最后一行**直接给出另一种方式的利息差**（「换成等额本金，利息少付 X 元」）——
  两种方式各算一遍再比，这是贷款里最常被追问的一句
- **逐期还款计划**：每期的月供、还掉的本金、利息与剩余本金，按顺序列出；
  先显示 24 期，底部按钮每次再加 24 期（合计与结论始终按全部期数算，表里少的只是行）
- **存款两种计息**：单利（每年利息恒定）与复利，复利可选按年 / 按季 / 按月滚；
  给出到期利息、到期本息与**实际年化**（复利按频率滚一年后高于名义利率，这一栏单独列出来）
- **存款逐年明细**：年初余额、当年利息、年末余额，逐年对得上（上一年年末 = 下一年年初）
- **输入不合法说清是哪一格**：金额、年利率、期限三格各自标红，一次只报一条、先报最前面那格；
  边界是金额 > 0 且最多 10 亿元、年利率 0–100%、期限 1–40 年（按整年填），
  报错文案直接写清边界而不是只说「输入有误」
- **四条例**：房贷 100 万 · 30 年 · 4.2%（等额本息）、车贷 20 万 · 5 年 · 4.9%（等额本金）、
  定存 10 万 · 3 年 · 2.5%（复利按年）、存款 5 万 · 2 年 · 1.5%（单利）
- **每个结果行都能一键复制**，复制的是纯数字（不带单位），便于贴回表格里复算
- **整页预渲染**：默认那套房贷示例的月供与还款计划都在 HTML 里，首屏可读

## 参数在哪调

**没有 `config.ts`**：业务参数只有金额 / 利率 / 期限三个上限（`MAX_AMOUNT` / `MAX_RATE` / `MAX_YEARS`）、
明细表一次多显示多少行（`SCHEDULE_STEP`）、四条示例（`INTEREST_EXAMPLES`）与三个输入框的默认值，
都就近放在 `core/interest.ts` 与 `core/store.svelte.ts` —— 没到「同一个数散在 `core/` 与 `ui/` 两边」
的门槛，按 `STRUCTURE §2 B` 就地放着。

## 档位

**L2**（`+page.svelte` + `core/store.svelte.ts` + `ui/` 面板）：按 `/subnet-calculator` 的同一个分法拆了 `ui/` 的
两块面板（`ResultPanel` / `SchedulePanel`）与工具条所在的 `Workspace.svelte`：
两块内容各自要独立滚动与状态条，摊在一个文件里会到 300 行且互不相干。
没有 `ui/styles.ts`（没有同一串样式出现两处的地方，面板骨架与表格样式都用 `$lib/ui/styles` 与 Tailwind）。

## 实现口径

- **金额一律按「分」存整数**：用「元」的浮点累加 360 期之后会对不上账，而还款计划表正是要逐行核对的东西
- **尾差落在最后一期**：前 n−1 期按公式算，最后一期直接把剩余本金还完 ——
  每期本金加起来恒等于借款额，最后一行余额是 0。代价是**等额本息的末期月供可能差几分**
  （每期利息取整到分会累积），结果卡里显示的月供是首月那期
- **等额本息月供公式** `P·r·(1+r)^n / ((1+r)^n − 1)`，零利率（`r = 0`）时退化成 `P / n`，不除零
- **等额本金的每期本金固定**，利息按剩余本金算，所以月供逐月递减；「每月递减」取前两期实际月供之差，
  不另行按 `本金 × 月利率` 推算（取整后两者可能差一分）
- **复利按年滚**：年增长因子 `(1 + r/f)^f`，逐年取整到分；频率越高到期越多
- **实际年化**就是上面那个因子减一，单利时等于名义利率 —— 复利按月时它会明显高于名义利率，
  这一栏就是为了让这件事看得见
- 贷款与存款两组方式控件**都常驻渲染**，不生效的那组 `opacity-60` + `aria-disabled`：
  切模式时工具条高度不能跳一下

## 已知取舍 / 暂不支持

- **不做提前还款与部分还款**：那要重排整个计划表（缩期 / 减月供两种口径），本轮先算清「一路还到底」
- **不做浮动利率（LPR 重定价）与组合贷**：利率一变就不是一条公式的事，且各家口径不同，容易算出一个看着权威的错数
- **不按月给存款计息的活期口径**：活期按日计息、季末结息，与这里的「按年 / 按季 / 按月滚」不是一回事
- **不算手续费、保险费与 IRR**：那是「综合资金成本」的口径，只给利率会低估真实成本；
  要做就另开一页把费用项列全
- **不做还款计划的导出（CSV / Excel）**：贴回表格里复算用复制就够了，导出要再引一套序列化

## 验证过什么

- 纯逻辑单测在 `core/interest.test.ts`（vitest 的 server project）：三个解析器各自的合法与非法输入、
  零利率退化、等额本金的手算锚点（12 万 1 年 12%：首期利息 1200、递减 100、总利息 7800）、
  本金合计等于借款额且末期余额归零、房贷量级校验（100 万 30 年 4.2% 落在 4890 元附近）、
  单利与复利的逐年数字、复利按月实际年化 12.68%、上一年年末等于下一年年初，以及金额与百分数格式化
