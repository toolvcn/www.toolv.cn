# 科学计算器 · /calculator

> 在线使用：<https://www.toolv.cn/calculator> ・ 数据全部本地处理，不上传、不落库

- **跟着敲跟着算**：输入框每改一个字符结果就更新，没有「按等号才算」这回事；「计算」按钮的唯一作用是把这条算式与结果记进历史。
- **四则与优先级**：`+ - * / % ^`，括号随便套；幂运算右结合（`2^3^2` = 512），一元负号可连写（`1 - -1`）。
- **隐式乘法**：`2(3 + 4)`、`2pi`、`3sin(30)` 都按乘法算；但两个光挨着的数不算——`2 3` 更像漏写运算符，静默算成 6 只会让人以为算对了，直接报错。
- **函数**：`sin cos tan asin acos atan`（随角度制 / 弧度制切换）、`ln log10 log2 exp sqrt cbrt abs round floor ceil`、`pow min max`（后两者多参数）。
- **常量**：`pi` / `e`，全角 `π` 也认；界面一排按钮点一下把函数或常量插到表达式末尾（追加，不替换）。
- **角度制 / 弧度制**：只影响三角函数的入参与反三角函数的出参，状态条里一直写着当前是哪一档。
- **结果实时可复制**：复制的是结果本身（出错时是「—」，空时提示），结果区下方回显一遍算式方便核对。
- **历史 20 条**：点一条把算式填回输入框，行尾叉掉单条，footer 一键清空；只存 `localStorage`（键 `toolv:calculator:history`），不上传；同一条算式连算两次不堆两行。
- **报错指到第几个字符**：括号没配对、函数后少 `(`、参数个数不对、不认识的名字、除数是 0、结果溢出、算出来是 NaN，各有各的中文提示；出错时结果区显示「—」，提示统一放在状态条。
- **全角符号顺手认掉**：`（）＋－×÷，−` 从别处粘过来也能算。
- **首屏可读**：默认表达式 `(12 + 8) * 3 / 2^2` 的结果在 SSR 的 HTML 里，刷新前就有数。

## 参数在哪调

没有 `config.ts`——业务参数少，未到建它的门槛，就近放在两处：`core/store.svelte.ts` 里的 `HISTORY_KEY`（`toolv:calculator:history`）、`MAX_HISTORY`（20）、`DEFAULT_EXPR`（`(12 + 8) * 3 / 2^2`），以及 `core/calc.ts` 里的 `SNIPPETS`（那一排插入按钮）。改上限或默认式子动这两处即可。

## 档位

L2。共享状态与编排在 `core/store.svelte.ts`（表达式、角度制、历史、`$derived` 结果），求值逻辑（词法 / 递归下降解析 / 函数表 / 格式化）在 `core/calc.ts`；面板拆成 `ui/Workspace.svelte`（工具条 + 插入按钮）、`ui/ResultPanel.svelte`、`ui/HistoryPanel.svelte` 三块。没有 `ui/styles.ts`（没有同一串样式出现两处的地方）。

## 实现口径

- 不 `eval`、不 `new Function`：表达式自己词法 + 递归下降解析再求值。站内其它工具都坚持不执行用户输入的字符串，这一页更不能开这个口子；代价是自己维护优先级表，换来「报错能指到第几个字符」。
- 不引依赖：表达式求值就那么点语法，引一个库反而要按它的错误格式说话，也违反「不为单个工具引入大型依赖」。
- 浮点噪声在显示层收拾：`0.1 + 0.2` 的二进制误差不是 bug，但显示成 `0.30000000000000004` 是为难用户——`formatNumber` 先收敛到 12 位有效数字，超出量程（`≥1e15` 或 `<1e-9`）再切科学计数法。
- 除零单独报错：不落到 `Infinity` 再被「结果超出范围」兜住（那样用户看到的是个看不懂的词）。
- 隐式乘法只认「数字后面紧跟括号 / 常量 / 函数」，不认「数字紧跟数字」，刻意避开的正是 `2 3` 这类漏写运算符。
- 历史只认长得对的条目：从 `localStorage` 恢复时逐条校验，脏数据直接丢掉而不是让页面崩。

## 已知取舍 / 暂不支持

- 不做变量与赋值（`x = 3` 之后用 `x`）：那要维护一套符号表与生命周期，本页定位是「一个算式算清」，不是脚本环境。
- 不做单位换算与进制转换：分别有 `/unit-converter` 与 `/radix-converter`，不在这里重复做。
- 不做阶乘 `!` 与把 `%` 当百分比：`!` 要区分后缀一元与逻辑非，`%` 在本页是取余（与 JS / Python 一致），两个含义挤一个符号最容易混。
- 不做绘图：函数图像是另一整块交互，本页只给数。
- 不做复数：`sqrt(-1)` 明确报错而不是返回 `NaN` 让人猜。

## 验证过什么

- 纯逻辑单测在 `core/calc.test.ts`（vitest 的 server project）：优先级与括号、一元负号、幂运算右结合、科学计数法、隐式乘法三种写法与「两个光挨着的数」要报错、角度制与弧度制下的三角与反三角、对数和根、多参数函数、常量与全角 `π`，以及空表达式 / 括号不配对 / 函数用法不对 / 不认识的名字 / 除零 / 溢出 / NaN 各自的中文报错，另有 `formatNumber` 的浮点收敛与科学计数法。
- 未做浏览器实测（无 axe / 几何量测条目）。
