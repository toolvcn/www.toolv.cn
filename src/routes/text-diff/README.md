# 文本对比 · /text-diff

> 在线使用：<https://www.toolv.cn/text-diff> ・ 数据全部本地处理，不上传、不落库

- **左右两栏逐行对比**：新增的行标绿、删除的行标红，未变的行原样列出，粘贴即出结果，不用点按钮
- **并排 / 合并两种视图**：并排视图把「删除 + 新增」配成同一行的左右两格，一眼看清改了什么；合并视图是一列带 `-` / `+` 前缀的文本，方便整段复制
- **三个忽略项**：可分别忽略大小写、行首尾空白与空行，只影响比较、不改显示的原文
- **行号按原文**：忽略空行时行号仍是原文里的行号，方便回原文件定位
- **状态播报明确**：脚注实时说明「新增 / 删除 / 未变」各多少行，完全一致、只显示前 1000 行、内容过大没做最优对齐各有各的说法
- 对比用自实现的 LCS（公共前后缀先对齐，只把真正不同的中间段交给动态规划），不引第三方 diff 库

## 参数在哪调

没有 `config.ts`，可调常量在 `core/diff.ts`：

- `MAX_CELLS = 2_000_000`：LCS 表的格数上限（约 8MB Uint32Array），超过就降级成「整段删除 + 整段新增」并提示，不跑会卡死的长循环
- 三个忽略项（`ignoreCase` / `ignoreWhitespace` / `ignoreBlank`）与结果显示上限在 `core/store.svelte.ts` 与 `ui/`

## 档位

**L2**（+page.svelte + core/ 纯函数 + ui/ 面板）：`core/diff.ts`（splitLines / diffLines / toSplitRows / toUnifiedText，自实现 LCS）+ `core/store.svelte.ts`。

## 实现口径

- **公共前后缀先对齐**：日常改动大多只在中间差几行，前缀后缀直接相等对齐，只把真正不同的中间段交给 DP，把动态规划规模压下一个量级
- **规模超限降级而非卡死**：中间段 `n × m > MAX_CELLS` 时退化为「整段删除 + 整段新增」并置 `degraded`，UI 明确说明「没做最优对齐」，不让用户等一个卡死的长循环
- **忽略项只动比较键**：行尾 CRLF 统一、忽略空行时跳过且行号仍取原文行号；忽略大小写 / 空白只改变 `key`，显示文本仍是原文（开启忽略项后并排视图右格用 `rightText` 显示真实原文）
- **并排配对按下标两两配对**：一段连续的删除 + 新增按下标配成 `change` 行，多出来的一侧独占一行，合并视图用 `-` / `+` / 空格 前缀

## 已知取舍 / 暂不支持

- 只做行级 diff，不做字符 / 单词级（一行内改几个字仍整行标红）；字符级差异留给更重的算法
- 不做「目录 / 多文件」递归对比，只比两段文本
- 不做语法感知（不按语言结构对齐），纯按行文本
- 超长结果的显示有截断（前 1000 行），复制的是完整 diff 文本
